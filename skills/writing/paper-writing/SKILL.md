# Paper Writing

Make the scientific logic clear to a capable first-time reader while preserving
the evidence and the user's edit scope.

## Load references conditionally

- Read [style-rules.md](references/style-rules.md) before changing prose.
- Read [section-playbook.md](references/section-playbook.md) for structural
  revision, front matter, captions, cover letters, or bilingual synchronization.
- Read [review-checklist.md](references/review-checklist.md) before final handoff.

## Core contract

1. Preserve numbers, denominators, citations, labels, terminology, qualifiers,
   and claim strength.
2. Trace every new or strengthened factual or causal statement to the supplied
   evidence. Report evidence gaps instead of filling them with plausible text.
3. Attribute contribution to the final method, system, dataset, or finding.
   Debugging effort and repairs that restore intended behavior are not
   contributions.
4. Respect the requested mode:
   - review-only returns findings without editing files;
   - language-only preserves structure, density, and unaffected wording;
   - structural revision reorganizes only the authorized scope.
5. Preserve deliberate author and venue conventions unless they conflict with
   scientific truth or explicit user instructions.

## Workflow

1. Read the target passage and enough surrounding material, figures, tables,
   and supplementary evidence to understand its role.
2. Record protected facts and the applicable edit contract.
3. For structural work, map the reader's path through need, problem, method,
   evidence, value, and limitations. For language-only work, keep that map as a
   diagnostic and edit the smallest necessary spans.
4. Revise only the required layers: structure, argument, contribution,
   terminology, sentences, evidence, and bilingual consistency.
5. Recheck claims against sources, compare the final diff with the edit
   contract, compile when applicable, and inspect changed rendered pages when
   layout may move.

## Output

Deliver the requested revision or review findings. Report protected evidence,
checks actually run, unavailable validation, and any unresolved source or
scope conflict.
