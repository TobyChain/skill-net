# Report style and structure rules

Read this reference before drafting or restructuring a report. Apply only the
rules the document type and edit scope need.

## Reader-first structure

1. **Executive summary first.** At most one page: conclusion, key numbers,
   recommendation, and the decision requested. A reader who stops here must
   leave with the correct message.
2. **Inverted pyramid per section.** Section thesis in the first sentence or
   paragraph; supporting detail in decreasing order of importance.
3. **One section, one message.** If a section needs "and also", split it or
   rename it to the covering message.
4. **Forward the reader.** State in the introduction which reader needs which
   section; cross-reference instead of repeating.

## Report patterns

- **Status report:** goal, current state, deltas since last period, risks,
  next actions with owners and dates.
- **Analysis report:** question, method and data boundary, findings ranked by
  importance, limitations, recommendation.
- **Review document:** criteria, verdict per criterion, evidence per verdict,
  required changes.
- **Decision memo:** options considered, evaluation against stated criteria,
  recommendation, risks and reversibility, decision requested.

Adapt the skeleton to the material; never force sections that have nothing to
say.

## Evidence and numbers

- Frame every number with its denominator, unit, period, and comparison base.
- Distinguish measurement from estimate from assumption; label each.
- Cite the source next to the claim, not in a distant appendix, unless the
  venue's format requires otherwise.
- State the confidence and the failure mode of the recommendation, not just
  the upside.

## Language

- Write the proposition directly; delete announcements of structure ("this
  section will discuss").
- Keep terminology stable: one term per concept, defined at first use.
- Prefer short declarative sentences for findings; keep hedging words only
   where the evidence is genuinely partial.
- Remove filler with no informational value ("it is worth noting that").

## Final gate

Before handoff: verify totals and cross-references, confirm every claim maps
to a source, check abbreviations introduced exactly once, and confirm the
executive summary still matches the body after the last edits.
