# 分析配方

## 仓库

读取 README、依赖清单、入口和目录树；找 3–7 个核心抽象并定位实现；追踪一个真实 happy path；从代码提取概念依赖；用可运行示例和源码位置支撑关键结论。大型仓库以 README 为索引，优先关键 10% 文件。

## 论文

抽取问题、假设、方法、公式、实验和局限；补齐先修概念；先解释直觉，再给形式化定义和推导；例题可构造小规模数据但需明确标注；练习从公式复现升级到假设分析和消融设计。

## 文章

获取全文和元数据；对当前事实与关键概念补充权威来源；区分作者观点、事实证据和编辑推断；把非线性叙述重排为知识依赖序列。

## 多源资料与已有 HTML

建立来源清单和访问状态；抽取概念、公式、实验、系统模块、术语别名和冲突；建依赖图与覆盖矩阵；审查缺失先修、定义晚于使用、无例题、无练习、来源不明和重复内容；定点修改，不因重构丢失已确认信息。
