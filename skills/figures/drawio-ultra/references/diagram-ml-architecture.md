# 深度学习模型架构图生成

Transformer / CNN / 检测网络 / 感受野 / 注意力机制等学术架构图的专用工作流与模板。视觉规范见 `style-academic.md`，XML 基础规则见 `xml-basics.md`。

## Step 1：明确图的核心信息

1. 确定图表类型：
   - 模型架构图：突出模块层级、数据流、重复结构和关键连接
   - 算法流程图：突出步骤顺序、输入输出、条件分支
   - 概念示意图：突出关键变量、计算关系、局部机制
   - 系统架构图：突出模块职责、数据/控制流、边界
2. 提取必要内容：
   - 有代码时，优先分析类结构、`forward` 方法、层堆叠关系和张量流向
   - 无代码时，从用户描述提取节点、层次、连接、重复次数和输入输出
   - 不确定的结构不要凭空补全；影响图意的假设在输出说明中标注

## Step 2：先设计布局，再写 XML

布局方向选择：

- 自下而上：神经网络前向传播、编码器/解码器堆叠
- 自上而下：步骤流程、决策流程、训练流程
- 自左向右：时序展开、多阶段 pipeline、特征提取链路
- 中心发散：注意力机制、多分支融合、模块内部机制

画布与间距要求见 `style-academic.md` 版式原则。

## Step 3：生成 XML

优先生成未压缩、可读的 XML，便于人工编辑和版本对比。基础模板见 `xml-basics.md`，节点样式见 `style-academic.md`。

## Step 4：添加辅助表达

1. **重复结构**：用 `x N`、`N layers` 或分组标题表示，不要机械复制多层导致图拥挤
2. **残差连接**：外侧虚线箭头，落点指向 `Add + Norm` 或融合节点
3. **跨模块信息流**：如 Encoder Memory → Cross-Attention，用清晰横向正交箭头并加说明框
4. **维度/参数标注**：只标关键维度，不把论文公式全塞进节点
5. **图题**：放图下方（y > 最低节点底边 + 30px）

## 常见模板结构

### Transformer 编码器/解码器
输入嵌入与位置编码、Multi-Head Self-Attention、Add + LayerNorm、FFN、Decoder Masked Attention、Encoder-Decoder Cross-Attention、Linear + Softmax、残差连接、`x N` 重复层。布局左右分列：Encoder 左、Decoder 右，数据流自下而上，Encoder Memory 横向输入 Cross-Attention。

### CNN / 检测网络
Input → Backbone → Neck → Head → Prediction，按阶段从左到右展开。复杂模块用容器概括，模块内部只展示对理解贡献最大的算子。特征图用 3D cube 节点（模板见 `xml-basics.md`），配维度标注。

### 感受野示意图
多层特征图网格、感受野高亮、计算公式框、参数说明。布局横向并列，颜色只强调被解释区域。

### 注意力机制图
Q/K/V、矩阵乘法、Scale、Softmax、加权求和、输出。自下而上或左到右，矩阵和向量对齐，避免箭头交叉。

## 质量自查

- 每个模块可追溯到用户描述、论文或代码
- 主路径 / 辅助路径 / 重复结构一眼可分辨
- 同类节点同色同尺寸同字号，连线样式一致
- 3D 节点的文本标签独立放置在图形下方
